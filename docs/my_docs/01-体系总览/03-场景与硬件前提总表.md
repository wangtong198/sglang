# 场景与硬件前提总表

写作门第 1 条：每条知识点写明场景，以及硬件或平台前提。下表是启动正文回填的行。行为都以本树源码里的分叉为准，运行时没有在对应硬件上实测，状态统一是 **源码路径推断，未实测**。

| 场景 | 硬件或平台前提 | 清单 ID | 状态 |
| --- | --- | --- | --- |
| 单机单卡，默认 HTTP | 设备能走该平台的默认后端。CUDA 是常见路径 | F01–F09、F20 | 源码路径推断，未实测 |
| 单机多卡张量并行 | `tp_size>1`，`dp_size=1`，`attn_dp_size=1` | F04、F97、F106 | 源码路径推断，未实测 |
| 模型副本数据并行 | `dp_size>1`，且不能同时 `attn_dp_size>1` | F97、F99、F192 | 源码路径推断，未实测 |
| Attention DP | `attn_dp_size>1`，`dp_size` 为 1。GPU 数仍由 TP 决定 | F76、F108、F192、F202 | 源码路径推断，未实测 |
| 流水并行 | `pp_size>1`。overlap schedule 会被关掉 | F80、F107、F196 | 源码路径推断，未实测 |
| 多机，非零 rank | 需要集合通信地址。业务 HTTP 在 rank 0 | F101、F199 | 源码路径推断，未实测 |
| `model_path` 为 `none` 或 `dummy` | 不下载权重。硬件运行时校验之后流水线返回 | F44 之后的早退 | 源码路径推断，未实测 |
| 扩散服务 | `--model-type diffusion` 或 auto 判定为扩散 | F24 | 源码路径推断，未实测 |
| 仅编码器 | `encoder_only`。可选再走 encoder gRPC | F21 | 源码路径推断，未实测 |
| SMG gRPC | `smg_grpc_mode`，或已折进去的 `grpc_mode` | F22 | 源码路径推断，未实测 |
| Ray | `use_ray`，且安装了 Ray 额外依赖 | F23 | 分叉已写；actor 内部待核 |
| Rust server | 环境变量 `SGLANG_RUST_SERVER` | F102、F204 | 源码路径推断，未实测 |
| 投机，目标与草稿各一块 KV | 算法非空，且本 PP 级要建草稿 | F113、F128、F194、F206 | 源码路径推断，未实测 |
| CUDA graph 与 post-capture KV | CUDA，且计划在捕获后按剩余显存改池 | F116、F117、F195 | 源码路径推断，未实测 |
| CP 组与 TP 组共享 | prefill CP，`attn_cp_size == tp_size`，架构是 Glm5Next 或 Qwen4Exp | F205 | 源码路径推断，未实测 |
| HPU | `handle_hpu_backends`：attention `torch_native`，sampling `pytorch` | F61 | 源码路径推断，未实测 |
| CPU | `handle_cpu_backends`。AMX 或 torch native。共享内存 all-reduce 的注释只提到 Intel AMX 与 arm64 | F61、F105 | 源码路径推断，未实测 |
| NPU | `handle_npu_backends`；分布式 init 里 `init_npu_backend` | F61、F105 | 源码路径推断，未实测 |
| MPS，非 MLX | `resolve_once` 先 `validate_mps_runtime`；流水线里关掉 overlap schedule | F44、F61 | 源码路径推断，未实测 |
| MLX | `use_mlx()` 的硬件门，以及 scheduler 上的 MLX worker | F44、F111 | worker 与 CUDA 路径逐步对齐待核 |
| XPU | sampling `intel_xpu`；默认关 decode 图，除非已被锁住 | F61 | 源码路径推断，未实测 |
| AMD ROCm | `handle_amd_specifics`；monokernel 在 F87。MegaMOE 另有环境变量提示 | F73、F87 | 源码路径推断，未实测 |
| NVIDIA megakernel | 图、attention、投机定稿之后校验。与 AMD monokernel 互斥 | F87 | 源码路径推断，未实测 |
| Mooncake 进程组 | CUDA 且 `elastic_ep_backend == "mooncake"` | F110 | 源码路径推断，未实测 |
| NIXL 协调 | `moe_a2a_backend == "nixl"` 时建全局 TCPStore | F109 | 源码路径推断，未实测 |
| MUSA 上的 prefill CP | `enable_prefill_cp` 且平台是 MUSA | F43 | 源码拒绝，未实测 |
| DeepSeek V4 池 | hybrid SWA 的 DSV4 用专用池类；NPU 用 NPU 变体 | F132 | 源码路径推断，未实测 |

还没回填的：D07、D16，以及特性、模型篇里的平台限制。那些目录展开时再加行。
