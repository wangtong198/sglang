# 阅读顺序

和 [00-规划与学习路径](../00-规划与学习路径.md) 同一条顺序。本页给第一次打开这套笔记的人。

1. [README](../README.md) 的五条写作门。
2. [00-规划与学习路径](../00-规划与学习路径.md) 的状态表：清单已完成，启动、请求接入与调度正文已写，下一步是流式与非流式响应。
3. [01-地图](01-地图.md)。
4. [清单](../调研笔记/00-全量知识点清单.md)。用它核对 ID，不把清单当已写完的深文。
5. 正文按清单顺序出现在 `02-流程` → `03-特性` → `05-模型` → `04-分布式`。启动、请求接入、调度与推理已展开。还没展开的目录只有 ID 列表。
6. 旗标查 [附录 05](../附录-选项索引/05-Server选项大全.md)，请求字段查 [附录 06](../附录-选项索引/06-Client请求选项大全.md)。
7. `docs/my_docs_archive/` 是旧扁平笔记，只作对照。

场景和硬件前提在展开时回填到 [03-场景与硬件前提总表](03-场景与硬件前提总表.md)。术语回填到 [04-术语表](04-术语表.md)。
