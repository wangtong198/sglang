# 多模态、扩散与 dLLM

占位。多模态走 LLM 的处理器，扩散有自己的 ServerArgs 和注册表，dLLM 是另一条推理循环。B86、B87、B96 是复审补上的。本页不写模型名单。

| ID | 特性 |
| --- | --- |
| B53 | 多模态 |
| B54 | 扩散 |
| B55 | dLLM |
| B86 | 编码器分离 |
| B87 | ASR |
| B96 | 扩散 cache-dit |

扩散启动分叉是 F24，编码器分离是 F21 / F187。F24 归 [02-流程/01-启动](../../02-流程/01-启动/README.md)，F187 在 A.14，归 [02-流程/03-调度与推理](../../02-流程/03-调度与推理/README.md)。扩散注册表是清单 C.5，归 [05-模型/01-注册表](../../05-模型/01-注册表.md)。
