## 本批没写死的缺口

- Ray 的 actor 如何替换 `mp.Process`：分叉点在 CLI 页，`RayEngine` 内部未逐行对照。待核。
- SMG gRPC 与 encoder-only 的进程内部不走默认 `Engine._launch_subprocesses`，这里只写分叉条件。
- `model_overrides/` 各模块的字段级改写不逐个抄。F63 写分发和 DeepSeek V4.1 的拒绝；单模型默认值归模型目录。
- `check_server_args` 的每条断言不逐条展开。它不在 pipeline 表内，调用点在进程拓扑。
- 扩散有自己的 `prepare_server_args`，不进 LLM 的 `run_resolution_pipeline`。
- 多卡、ROCm、NPU、DeepEP 没有实跑记录。
