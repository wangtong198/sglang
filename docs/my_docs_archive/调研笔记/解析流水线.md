# 调研笔记：`run_resolution_pipeline` 的 hook 顺序

对照文件：`python/sglang/srt/arg_groups/pipeline.py` 的 `run_resolution_pipeline`。S2 的全部改写都发生在这里。`prepare_server_args` 只做 argparse，不会跑这张表。

顺序是依赖顺序，不是字母顺序。插件可以替换单个 hook，不能换顺序（`run_hook`）。

| 次序 | hook | 这一步做完什么 |
| --- | --- | --- |
| 1 | 保存 `_raw_input` | 操作者原始输入被冻结，后面的改写进 `_resolved_overrides` |
| 2 | `handle_deprecated_dp_attention` | 旧的 `--enable-dp-attention` 收成 `attn_dp_size` |
| 3 | `handle_mega_moe` | MegaMOE 的提前约束 |
| 4 | 返回模式、水印、媒体 URL、HiCache 比例、offload 兼容、采样 mask、辅助隐状态 | 还不需要模型 config 的检查 |
| 5 | `validate_prefill_cp_platform`、`handle_hardware_runtime_validation` | 硬件不支持就在下载模型之前失败 |
| 6 | `model_path` 为 `none`/`dummy` 时提前返回 | 不建模型 |
| 7 | `handle_model_source_paths` | 路径、revision、远程权重 |
| 8 | `apply_muse_spark_env_defaults` | 必须在显存启发式之前 |
| 9 | 多模态、SSL、ASR、废弃旗标、缺省值 | |
| 10 | `handle_expert_pack` | GGUF expert pack 可能换成生成的本地元数据，并锁定 eager |
| 11 | `handle_pd_disaggregation` | PD 旗标先于 CUDA graph |
| 12 | KV 开关的前置校验、`handle_decode_context_parallelism` | DCP 与 prefill CP 互斥在这里 |
| 13 | `handle_dwdp` | 必须在 CUDA graph 和 data parallel 之前 |
| 14 | `handle_cuda_graph_config` | decode/prefill 两相图 |
| 15 | 平台后端：HPU、CPU、NPU、MPS、XPU、对称内存、平台默认 | |
| 16 | `handle_gpu_memory_settings` | `mem_fraction_static` 等 |
| 17 | `handle_model_specific_adjustments` | DeepSeek-V4 的 `dsv4` attention、`page_size=256`、V4.1 特征拒绝 |
| 18 | 采样后端默认、确定性、attention 兼容、Mamba、页大小、AMD、grammar | |
| 19 | `handle_data_parallelism` | attention DP 的整除、保守系数、chunk 缩小 |
| 20 | `handle_context_parallelism` | prefill CP / `attn_cp_size` |
| 21 | `handle_kv_cache_sharding` | 页、attention、预算都定了之后 |
| 22 | `handle_moe_kernel_config`、`handle_a2a_moe` | DeepEP / mori 的 EP 改写在 post-process，由这里触发 |
| 23 | shared expert TP、EPLB、elastic EP | |
| 24 | PP 关闭 overlap | `pp_size>1` 强制 `disable_overlap_schedule` |
| 25 | `handle_speculative_decoding` | DSPARK / EAGLE 的草稿路径与断言 |
| 26 | layernorm SP、load format、encoder 分离、tokenizer 批、环境变量、cache 兼容、unified pool、dLLM | |
| 27 | NVIDIA megakernel / AMD monokernel | 两个都开时一次报齐 |
| 28 | 再次 `handle_kv_cache_sharding`，DeepEP v2 的 token 预算 | 能力调整可能晚改 attention |
| 29 | `_resolution_finished = True` | 之后再写字段会抛 `AttributeError` |

`check_server_args`（`validation_hook.py`）不在这张表里。它在 S3，`Engine._launch_subprocesses` 里调用，负责 `(tp*pp) % nnodes == 0` 和「多节点禁止 `dp_size>1`」。
